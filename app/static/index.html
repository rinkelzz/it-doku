Unverschlüsselte Verbindung aus dem Internet. Die IT-Dokumentation ist gerade per http:// von außen erreichbar – Passwort und Anmeldung können mitgelesen werden. Bitte den Port nicht direkt freigeben, sondern über den Reverse Proxy von DSM mit https://.

Standorte

Mit nur einem Standort blendet die App die Standort-Auswahl überall aus. Internetanschluss und Netzwerkplan pflegst du unter Netzwerk.

Gerätetypen

Vorbelegt, frei änderbar. Typen mit Geräten lassen sich nur zusammenlegen, nicht einfach löschen.

Wer hat Zugang zum Tresor?

Freischalten geht nur für Benutzer mit Vollzugriff und nur bei offenem Tresor. Die Person bekommt einen Einladungscode (z. B. am Telefon durchgeben, 7 Tage gültig) und legt damit ihr eigenes Tresor-Passwort fest – du erfährst es nie.

🛰️ Agenten

Ein Agent läuft auf einem Server oder PC (Windows, Linux, macOS), meldet sich täglich und nach jedem Start und schickt Hardware, System, Datenträger, Netzwerk, installierte Software, Updates und Dienste. Das Gerät wird über Seriennummer oder Rechnername gefunden – oder automatisch angelegt. Am Server muss kein Port offen sein.

Einstellungen

So erreichen die Agenten die IT-Dokumentation:
Von außen: DSM → Systemsteuerung → Anmeldeportal → Erweitert → Reverse Proxy, Quelle https://doku.kunde.de (Port 443, Zertifikat von Let's Encrypt), Ziel http://localhost:8780.
Per VPN: die interne Adresse, z. B. http://192.168.10.5:8780 – unverschlüsselt nur im VPN/LAN sinnvoll (der Agent fragt dafür eine Bestätigung ab).

Stille Agenten erscheinen auf der Übersicht und in der wöchentlichen Fristen-Mail.

Fristen-Mail

Eine Sammel-Mail pro Woche mit abgelaufenen und bald ablaufenden Lizenzen, Domains, Zertifikaten und Garantien – nur wenn etwas fällig ist. Dazu je Eintrag eine Erinnerung 14 Tage vorher und am Ablauftag.

Datensicherung

Jede Nacht eine geprüfte Sicherung der Datenbank: immer im Paketordner (die letzten 7) und zusätzlich in einem freigegebenen Ordner, den Hyper Backup mitsichern kann. Achtung: Beim Deinstallieren des Pakets wird der Paketordner gelöscht – deshalb unbedingt einen freigegebenen Ordner eintragen.

Schreibrechte für den Ordner einrichten
  1. DSM → Systemsteuerung → Freigegebener Ordner → z. B. backup auswählen (oder neu anlegen) → Bearbeiten.
  2. Reiter Berechtigungen → oben links im Auswahlfeld System-interner Benutzer wählen.
  3. Bei itdoku den Haken Lesen/Schreiben setzen → Speichern.
  4. Hier als Ordner z. B. /volume1/backup/itdoku eintragen und speichern – der Unterordner wird angelegt.
Die Sicherungen enthalten alle Daten, Passwort-Hashes und (verschlüsselt) den Tresor – den Ordner bitte nicht für alle freigeben. Das Mail-Passwort wird nicht mitgesichert.

Updates

…

Updates kommen über das Paket-Zentrum – einmalig einrichten:

  1. Paket-Zentrum → Einstellungen → Allgemein → Vertrauensebene: Beliebiger Herausgeber.
  2. Paket-Zentrum → Einstellungen → Paketquellen → Hinzufügen: Name IT-Dokumentation, Ort http://127.0.0.1:8780/spk
  3. Neue Versionen erscheinen dann im Paket-Zentrum unter Installiert mit „Aktualisieren“ (oder automatisch, wenn dort automatische Updates eingeschaltet sind). Daten und Einstellungen bleiben erhalten.
